# О программе
OSEmulator - эмулятор для языка оболочки ОС.

Этап 1. REPL
Цель: создать минимальный прототип. Большинство функций в нем пока
представляют собой заглушки, но диалог с пользователем уже поддерживается.
Требования:
1. Приложение должно быть реализовано в форме графического интерфейса
   (GUI).
2. Заголовок окна должен содержать имя VFS.
3. Реализовать простой парсер, который разделяет ввод на команду и
   аргументы по пробелам.
4. Сообщить об ошибке выполнения команд (неизвестная команда, неверные
   аргументы).
5. Реализовать команды-заглушки, которые выводят свое имя и аргументы: ls,
   cd.
6. Реализовать команду exit.
7. Продемонстрировать работу прототипа в интерактивном режиме.
   Необходимо показать примеры работы всей реализованной
   функциональности, включая обработку ошибок.
8. Результат выполнения этапа сохранить в репозиторий стандартно
   оформленным коммитом.

# Запуск приложения
Для запуска приложения достаточно запустить файл `run.bat`.

# Поддерживаемые функции
## ls
### Описание
На данном этапе команда реализована в виде заглушки.
### Примеры использования

#### Без аргументов
Ввод:
```
$ ls
```
Вывод:
```
Введена команда ls.
```

#### С аргументами
Ввод:
```
$ ls a b c
```
Вывод:
```
Вызвана команда ls.
Аргументы:
[0] a
[1] b
[2] c
```

## exit
### Описание
> Завершает работу приложения и закрывает окно.

### Примеры использования

#### Без аргументов
Ввод:
```
$ exit
```

После нажатия Enter приложение завершит работу.

#### С аргументами

> Ввод аргументов **не поддерживается.**
> Функция не поддерживает аргументы, поэтому передача аргументов вызовет ошибку.

Ввод:
```
$ exit a b c
```
Вывод:
```
Неверный аргумент: a
```

# Обработка ошибок
## Неизвестная команда
При вводе неподдерживаемой команды в терминал выводится сообщение об ошибке.
Пример ввода:
```
$ test
```
Вывод:
```
Неизвестная команда: test
```
## Неверный аргумент
Если переданный аргумент не поддерживается функцией, в терминал выведется сообщение об ошибке.
Ввод:
```
$ exit a b c
```
Вывод:
```
Неверный аргумент: a
```
