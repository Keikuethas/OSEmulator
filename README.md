# Аргументы командной строки

Синтаксис аргументов: `<имя>=<значение>`
Пример: `vfs=C:\`
**Если передано несколько аргументов с одним именем**, будет обработано только последнее полученное
значение.

Если в аргумент, принимающий путь к файлу или папке, передан **относительный путь**, поиск ведётся
относительно текущей директории VFS.

## VFS

Задаёт расположение виртуальной файловой системы.
**По умолчанию** - `C:\`

## Script

Задаёт расположение стартового скрипта, который должен выполнить эмулятор.
**Важно**: путь задаётся относительно корня VFS.
**По умолчанию** - пустой.
Строки, по какой-либо причине вызывающие ошибку, не выполняются.
Если скрипт не найден, выводится сообщение об ошибке (неверный аргумент).

Пример:
`test.script`:

```
ls
idk
exit 0
ls 1 2 3
```

Вывод:

```
$ ls
Вызвана команда ls.
$ ls 1 2 3
Вызвана команда ls.
Аргументы:
[0] 1
[1] 2
[2] 3
```

# Поддерживаемые функции

## ls

### Описание

Выводит список файлов, лежащих в текущей директории VFS.

### Примеры использования

#### Без аргументов

Ввод:

```
$ ls
```

Вывод:

```
Type     Name

Dir      newDir
File     newFile.txt

```

#### С аргументами

Функция принимает 1 аргумент - путь к директории VFS, содержимое которой нужно вывести на экран.
> Если путь начинается с /, он трактуется как абсолютный (от корня VFS), иначе - как относительный

При передаче двух и более аргументов выводится ошибка.
Ввод:

```
$ ls /newDir
```

Вывод:

```
Type     Name

Dir      newDir2
File     newFile2.txt
```

## cd

### Описание

Изменяет текущую директорию на заданную.

### Примеры использования

#### Без аргументов

Ввод:

```
$ cd
```

Результат: ничего не происходит.

#### С аргументами
Функция принимает 1 аргумент - путь к директории VFS.
> Если путь начинается с /, он трактуется как абсолютный (от корня VFS), иначе - как относительный

Ввод:

```
$ cd /newDir
```

Результат: рабочая директория изменится на `root/newDir`

## exit

### Описание

Завершает работу приложения и закрывает окно.

### Примеры использования

#### Без аргументов

Ввод:

```
$ exit
```

Результат: приложение завершит работу.

#### С аргументами

> Ввод аргументов **не поддерживается.**
> Функция не поддерживает аргументы, поэтому передача аргументов вызовет ошибку.

## tree

### Описание

Строит иерархическое дерево папок и файлов, лежащих в текущей директории.

### Примеры использования

#### Без аргументов

Ввод:

```
$ tree
```

Вывод:
```
dir1
- file1.txt
dir2
- dir 3
- - fileA.txt
- - fileB.txt
```

#### С аргументами

Функция принимает 1 аргумент - путь к директории VFS, по содержимому которой нужно построить дерево.
> Если путь начинается с /, он трактуется как абсолютный (от корня VFS), иначе - как относительный

Ввод:

```
$ tree /system
```

Вывод:
```
sysDir1
- sysFile1.txt
sysDir2
- sysDir 3
- - sysFileA.txt
- - sysFileB.txt
```
# Обработка ошибок

## Неизвестная команда

При вводе неподдерживаемой команды в терминал выводится сообщение об ошибке.
Пример ввода:

```
$ test
```

Вывод:

```
Неизвестная команда: test
```

## Неверный аргумент

Если переданный аргумент не поддерживается функцией, в терминал выведется сообщение об ошибке.
Ввод:

```
$ exit a b c
```

Вывод:

```
Неверный аргумент: a
[пояснение]
```
