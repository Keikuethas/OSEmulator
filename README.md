# О программе

OSEmulator - эмулятор для языка оболочки ОС.

**Этап 3. VFS**
Цель: подключить виртуальную файловую систему (VFS).
Требования:
1. Все операции должны производиться в памяти. Запрещается распаковывать
   или иным образом модифицировать данные VFS, за исключением
   возможных служебных команд.
2. Источником VFS является директория на диске пользователя.
3. Создать несколько скриптов реальной ОС, в которой выполняется эмулятор.
   Включить в каждый скрипт вызовы эмулятора для тестирования работы c
   различными вариантами VFS (минимальный, несколько файлов, не менее 3
   уровней файлов и папок).
4. Создать стартовый скрипт для тестирования всех реализованных на этом и
   прошлых этапах команд. Добавить туда примеры всех режимов команд,
   включая работу с VFS и обработку ошибок.
5. Результат выполнения этапа сохранить в репозиторий стандартно
   оформленным коммитом.

# Аргументы командной строки

Синтаксис аргументов: `<имя>=<значение>`
Пример: `vfs=C:\`
**Если передано несколько аргументов с одним именем**, будет обработано только последнее полученное значение.

Если в аргумент, принимающий путь к файлу или папке, передан **относительный путь**, поиск ведётся
относительно текущей директории VFS.

## VFS

Задаёт расположение виртуальной файловой системы.
**По умолчанию** - `C:\`

## Script

Задаёт расположение стартового скрипта, который должен выполнить эмулятор.
**Важно**: путь задаётся относительно корня VFS.
**По умолчанию** - пустой.
Строки, по какой-либо причине вызывающие ошибку, не выполняются.
Если скрипт не найден, выводится сообщение об ошибке (неверный аргумент).

Пример:
`test.script`:
```
ls
idk
exit 0
ls 1 2 3
```

Вывод:
```
$ ls
Вызвана команда ls.
$ ls 1 2 3
Вызвана команда ls.
Аргументы:
[0] 1
[1] 2
[2] 3
```

# Поддерживаемые функции

## ls

### Описание

На данном этапе команда реализована в виде заглушки.

### Примеры использования

#### Без аргументов

Ввод:

```
$ ls
```

Вывод:

```
Введена команда ls.
```

#### С аргументами

Ввод:

```
$ ls a b c
```

Вывод:

```
Вызвана команда ls.
Аргументы:
[0] a
[1] b
[2] c
```

## cd

### Описание

> На данном этапе команда реализована в виде заглушки.

### Примеры использования

#### Без аргументов

Ввод:

```
$ cd
```

Вывод:

```
Введена команда cd.
```

#### С аргументами

Ввод:

```
$ cd a b c
```

Вывод:

```
Вызвана команда cd.
Аргументы:
[0] a
[1] b
[2] c
```

## exit

### Описание

> Завершает работу приложения и закрывает окно.

### Примеры использования

#### Без аргументов

Ввод:

```
$ exit
```

После нажатия Enter приложение завершит работу.

#### С аргументами

> Ввод аргументов **не поддерживается.**
> Функция не поддерживает аргументы, поэтому передача аргументов вызовет ошибку.

Ввод:

```
$ exit a b c
```

Вывод:

```
Неверный аргумент: a
```

# Обработка ошибок

## Неизвестная команда

При вводе неподдерживаемой команды в терминал выводится сообщение об ошибке.
Пример ввода:

```
$ test
```

Вывод:

```
Неизвестная команда: test
```

## Неверный аргумент

Если переданный аргумент не поддерживается функцией, в терминал выведется сообщение об ошибке.
Ввод:

```
$ exit a b c
```

Вывод:

```
Неверный аргумент: a
```
