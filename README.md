# О программе

OSEmulator - эмулятор для языка оболочки ОС.

Этап 2. Конфигурация
Цель: сделать эмулятор настраиваемым, то есть поддержать ввод параметров
пользователя в приложение. Организовать для этого этапа отладочный вывод всех
заданных параметров при запуске эмулятора.

**Требования:**

1. Параметры командной строки:
   – Путь к физическому расположению VFS.
   – Путь к стартовому скрипту.
2. Стартовый скрипт для выполнения команд эмулятора: выполняет команды
   последовательно, ошибочные строки пропускает. При выполнении скрипта
   на экране отображается как ввод, так и вывод, имитируя диалог с
   пользователем.
3. Создать несколько скриптов реальной ОС, в которой выполняется эмулятор.
   Включить в каждый скрипт вызовы эмулятора для тестирования всех
   поддерживаемых параметров командной строки.
4. Результат выполнения этапа сохранить в репозиторий стандартно
   оформленным коммитом.

# Аргументы командной строки

Синтаксис аргументов: `<имя>=<значение>`
Пример: `vfs=C:\`
**Аргументы обрабатываются последовательно** в соответствии с порядком их ввода. Возможна передача
одного и того же аргумента несколько раз. Таким образом, порядок передачи аргументов существенно
влияет на работу программы.

Если в аргумент, принимающий путь к файлу или папке, передан **относительный путь**, поиск ведётся
относительно текущей директории VFS.

## VFS

Задаёт расположение виртуальной файловой системы.
**По умолчанию** - директория, из которой запускается проект.

## Script

Задаёт расположение стартового скрипта, который должен выполнить эмулятор.
**По умолчанию** - пустой.
Строки, по какой-либо причине вызывающие ошибку, не выполняются.

Пример:
`test.script`:
```
ls
idk
exit 0
ls 1 2 3
```

Вывод:
```
$ ls
Вызвана команда ls.
$ ls 1 2 3
Вызвана команда ls.
Аргументы:
[0] 1
[1] 2
[2] 3
```

# Поддерживаемые функции

## ls

### Описание

На данном этапе команда реализована в виде заглушки.

### Примеры использования

#### Без аргументов

Ввод:

```
$ ls
```

Вывод:

```
Введена команда ls.
```

#### С аргументами

Ввод:

```
$ ls a b c
```

Вывод:

```
Вызвана команда ls.
Аргументы:
[0] a
[1] b
[2] c
```

## cd

### Описание

> На данном этапе команда реализована в виде заглушки.

### Примеры использования

#### Без аргументов

Ввод:

```
$ cd
```

Вывод:

```
Введена команда cd.
```

#### С аргументами

Ввод:

```
$ cd a b c
```

Вывод:

```
Вызвана команда cd.
Аргументы:
[0] a
[1] b
[2] c
```

## exit

### Описание

> Завершает работу приложения и закрывает окно.

### Примеры использования

#### Без аргументов

Ввод:

```
$ exit
```

После нажатия Enter приложение завершит работу.

#### С аргументами

> Ввод аргументов **не поддерживается.**
> Функция не поддерживает аргументы, поэтому передача аргументов вызовет ошибку.

Ввод:

```
$ exit a b c
```

Вывод:

```
Неверный аргумент: a
```

# Обработка ошибок

## Неизвестная команда

При вводе неподдерживаемой команды в терминал выводится сообщение об ошибке.
Пример ввода:

```
$ test
```

Вывод:

```
Неизвестная команда: test
```

## Неверный аргумент

Если переданный аргумент не поддерживается функцией, в терминал выведется сообщение об ошибке.
Ввод:

```
$ exit a b c
```

Вывод:

```
Неверный аргумент: a
```
